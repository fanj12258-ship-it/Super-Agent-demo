故事线定位：模拟 FDE 在项目启动或售前诊断初期，进入新建的企业公共空间，从输入企业与业务背景出发，由 Super Agent 命中【企业全景规划与场景推导最佳实践】，连续完成企业档案构建 → 业务现状全景拆解与聚焦痛点确认 → AI 场景规划推导的端到端过程
故事线定位：模拟 FDE 在售前演示或早期 POC 阶段，已有明确单点业务想法，不需要做企业全景规划；先通过直接建场景进入该单场景，再在单场景下要求“快速搭个能试跑的 Demo”，由 Super Agent 命中【快速 Demo 验证】，以最小假设、跳过复杂前置需求设计、中间不停审，连跑出可对话试跑的智能体；随后 FDE 实际试跑 Demo，发现演示效果需要小修小补（现实中第一版生成的 Demo 不可能直接拿去见客户），在 Demo 主线下快速做轻量调整，达到可拿去给客户演示的状态。
故事线定位：模拟 FDE 在故事线 2 跑通【季度绩效配额核算与自评答疑】快速 Demo 并做完小修小补演示给客户后，客户决定正式立项投入生产；FDE 在同一个单场景下，把场景从 Demo 一步步推进到产品方案与客户对齐、业务规则核实、生产级技术方案定稿、本体对象集独立构建调试、智能体构建组装，以及在联调中经历一次由需求变化和规则变化引起的一连串实现逻辑变更，最终验收达标上线的完整现实过程。本故事线的关键特征是【Demo 转生产】
