Sales store allocation Agent MVP

Goal

This MVP supports HQ/warehouse → sales-store allocation. It first produces explainable recommendations from transparent rules; later a conversational Agent can adjust strategy, lock stores, recompute, and export.

Input data

Templates live under templates/:

  • inventory.csv：SKU allocatable stock, case pack, minimum allocation unit.
  • stores.csv：Store basics, tier, region priority, promo flags.
  • sales.csv：Store-SKU last 7/14/30-day sales, on-hand, inbound.
  • targets.csv：Store-SKU target inventory or demand.
  • rules.csv：Floors, caps, locks, and block flags.

Sample data lives under examples/.

Core logic

  1. Compute true gap: 
    gap = max(target - on_hand - inbound, 0)
  2. Compute store-SKU allocation weight: 
    weight =
  last_30d_sales_norm * 0.40
+ store_tier_score    * 0.25
+ sell_through_score  * 0.20
+ promo_store_score   * 0.15
  3. Apply rules:
    • Blocked stores get zero allocation.
    • Locked quantities are satisfied first.
    • Key-store floors are satisfied next.
    • Recommended qty cannot exceed gap or cap.
    • Round to case pack or minimum unit.
    • When stock is short, distribute remainder by weight.

Strategy parameters

The script supports three strategies:

  • balanced：Balanced — good for routine replenishment.
  • growth：Growth — tilts to high-sales / high-tier stores.
  • coverage：Coverage — spreads basic stock across more stores.

How to run

From the current directory:

python3 outputs/sales_allocation_agent/src/allocate.py \
  --input-dir outputs/sales_allocation_agent/examples \
  --output-dir outputs/sales_allocation_agent/results \
  --strategy balanced

Output files:

  • allocation_result.csv：Allocation recommendations.
  • allocation_alerts.csv：Exception alerts.

Or run the conversational Agent prototype:

python3 outputs/sales_allocation_agent/src/agent.py

Example commands:

allocate with growth strategy
run a coverage pass
balanced allocation, input dir outputs/sales_allocation_agent/examples
show last-run summary
exit

Path to a conversational Agent

Wrap the algorithm as a tool the Agent owns:

  • Detect uploaded spreadsheet fields.
  • Ask for missing fields or auto-map near matches.
  • Pick strategy from the user’s wording.
  • Explain allocation rationale per SKU/store.
  • Support natural-language tweaks like “give Shanghai A stores +20%” or “seed new SKUs to key stores first.”
